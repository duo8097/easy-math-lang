# Audit: 2026-10-21

Base: v4.2.0, commit `7ac5264e98701c457c20c44b3571a38fb61b9452`.

## Findings and fixes

| Area | Reproduction / previous behavior | Result |
| --- | --- | --- |
| Input preservation | Exporting to the source path (including a symlink or hard link) overwrote the source with binary output. A custom source-map path could overwrite it too. | Reject source aliases and conflicting output/intermediate/map destinations before writing artifacts. |
| Default export filename | `--format svg doc.ezmath` produced SVG bytes in `doc.pdf`; the API had the same mismatch. | Default filename uses the selected format's extension. Explicit output names still take precedence. |
| Editor assets | Exported Typst referred to temporary plot/vector SVGs that were deleted. Different exports also shared `preview-*` asset names. | Copy assets beside the export and use the exported document's stem for asset names. |
| Page ordering | A 12-page image export listed pages as 1, 10, 11, 12, 2, etc. | Collect only numbered page siblings and sort numerically. |
| Stale page discovery | Reusing a preview directory after reducing page count returned old pages, or an old single-page output instead of new multipage files. | Remove the exact current output and its numbered siblings before recompiling. |
| Page patterns | A one-page editor image export to `page-{p}.svg` left a literal `{p}` in the filename. | Expand the page pattern for both one-page and multipage exports. |
| Preview concurrency | Source writes occurred before the compile lock, allowing another render to replace a pending render's input. | Hold the lock across source writes, compilation and output discovery. |
| Relative images in editor | Preview and Export As resolved image paths from the temporary directory instead of the saved document's directory. | Pass the saved source path through the worker/export helpers and stage images inside the temporary Typst root. Exported Typst/HTML carries staged assets. |
| Plot arithmetic | Constant subexpressions such as `9^9^9` used unbounded Python bigint exponentiation even though calc guarded it. | Share calc's scalar exponent guard with the plot evaluator. NumPy array arithmetic remains unchanged. |
| Failed diagram renders | A failed SVG write left a Matplotlib figure registered after each attempt. | Close plot/vector figures in `finally`, including failure paths. |
| Variable diagnostics | Checking `<x> and <<x>>` replaced the operator-adjacent occurrence too. | Replace only the recorded undefined-variable spans, preserving operators. |
| Comments | `//` inside multiline math was stripped, and fenced literal code lost comments. | Track math/fence state across lines; ignore delimiters in removed comments, raw print spans and assignment control lines. |
| Resolution validation | Non-finite/fractional/bool API PPI values could raise or be silently coerced. | Reject invalid values before creating build files. |

## Validation

- Original suite: **769 passed, 3 skipped**.
- Updated full suite: **802 passed, 3 skipped** (`QT_QPA_PLATFORM=offscreen uv run pytest tests/ -q`).
- Added **33 regression cases**, including real Typst compilation of exported documents after their temporary directories and original image files are removed.
- All **7** checked-in `.ezmath` examples compiled to real PDFs through the CLI with `--strict`, using temporary copies.
- **600** seeded generated input documents (seed 8097; mixed valid/malformed syntax) produced no unhandled exceptions during Typst-source export. This is a robustness smoke check, not a correctness proof.
- `git diff --check` passed.

## Scope and limits

Validation used Python 3.12 on Linux and offscreen Qt. The three opt-in Windows packaged-binary tests were skipped because a Windows `dist/` build was not available. Windows/macOS installers and native desktop behavior still need their platform CI or real hardware. The audit exercises compiler, export, editor and LSP behavior covered by the suite; passing these checks does not prove the absence of all possible defects.
