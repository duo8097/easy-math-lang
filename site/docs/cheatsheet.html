Run the compiler

uv run easy-math-lang doc.ezmath              → doc.pdf (next to your file)
uv run easy-math-lang doc.ezmath out.png      → image(s)
uv run easy-math-lang --strict doc.ezmath     → exit non-zero on errors (CI)
uv run easy-math-lang --help                  → all options

Installed the app? Just easy-math-lang doc.ezmath (or press Ctrl+B

in the editor). See Export.

> Decimal rule: inside calc always use a dot (3.5, never 3,5).

> In commands, , separates arguments: *frac(3,5) is 3 over 5.

Separators — one rule

, and ; separate arguments everywhere. When ; is present it wins,

so big numbers keep their commas: *frac(100,000 ; 2).

*frac(2, 3)          same as   *frac(2 ; 3)
*line(A, B)          same as   *line(A ; B)
*table(a ; b | c ; d)          rows split on |, cells on ;

Draw geometry

*draw(
    *point(A = 0, 0)
    *point(B = 4, 0)
    *point(C)                    // placed automatically
    *distance(A ; C ; 3)         // a rule instead of coordinates
    *perp(A ; B ; A ; C)
    *triangle(A ; B ; C)
    *right-angle(B ; A ; C)
)

You describe relationships; the solver finds the positions.

Full guide: Drawing geometry.

You typeMeaning
*distance(A ; B ; 5)AB has length 5
*perp(A ; B ; C ; D)AB ⊥ CD (3 args: AB ⊥ BC)
*parallel(A ; B ; C ; D)AB ∥ CD
*on-line(A ; B ; C)C lies on line AB
*on-circle(O ; 5 ; A)A lies on circle (O, 5)
*equal-length(A ; B ; C ; D)AB = CD
*equal-angle(A ; B ; C ; D ; E ; F)angle ABC = angle DEF (equality marks on both)
*midpoint(A ; B ; M)M is the midpoint of AB
*intersection(P ; line(A ; B) ; line(C ; D))P is where the lines cross

Construction points

A point can be computed instead of free — write a constructor on the

right of =:

You typeMeaning
*point(M = midpoint(A ; B))halfway between A and B
*point(F = foot(P ; line(A ; B)))perpendicular foot of P
*point(R = reflect(P ; line(A ; B)))P mirrored across the line
*point(P = intersect(line(A ; B) ; line(C ; D)))where two lines cross
*point(P = intersect(line(A ; B) ; circle(O ; 3) ; 1))k = 1 or 2 picks the solution
*point(G = centroid(A ; B ; C))triangle center of mass
*point(O = circumcenter(A ; B ; C))circle-through-the-corners center
*point(I = incenter(A ; B ; C))inscribed-circle center
*point(H = orthocenter(A ; B ; C))altitudes' meeting point

Constructors nest inside constructors (midpoint(A ; midpoint(B ; C))),

and constraints may use the derived points. Ordering rules and error

cases: Construction points → geometry.md.

Plot a function

*plot(x^2, -5, 5)
*plot(sin(x), -10, 10)

Creates doc-plot-1.svg next to your file and embeds it automatically.

Only functions of x; write for multiplication (2x, not 2x).

If something goes wrong

MessageWhat it means
[Error] Line 7: undefined variable <widht> (with the source line + caret under the token)Typo in a variable name
[Warning] … unknown command *fract …Misspelled command — a suggestion is printed
[Calc Error: division by zero]calc() tried to divide by 0
Compiled … with 2 error(s), 1 warning(s)PDF was written anyway; fix these or use --strict

Every message points at a spot in your .ezmath file: the first line

says the line number, the lines under it show the real source line and

a caret under the exact character (File "doc.ezmath", line 7, column 9).
