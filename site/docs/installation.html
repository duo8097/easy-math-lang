Option A — Windows installer (easiest)

Requires Windows 10 version 1809 (build 17763) or newer, 64-bit

(the installer refuses to run on older systems).

  1. Download EasyMathLang-Windows-x64-Setup.exe from the latest stable release on the

GitHub Releases page

(or the nightly artifact under Actions -> "Build Installers").

  1. Run it and follow the steps. Two options are offered:
  • Create a desktop shortcut (off by default).
  • Add compiler/LSP to PATH (off by default) — tick this only if you

want to run easy-math-lang from a terminal. It appends to your

user PATH (HKCU\Environment), so no extra permissions are needed

for that step.

  1. Launch Easy Math Editor from the Start Menu.

No further setup is needed: the editor finds its helper programs

(easy-math-lsp, easy-math-lang) next to itself automatically —

see Desktop editor. The

editor and the helpers all install into one folder,

C:\Program Files\EasyMathLang\bin\, which also holds the single

shared library directory _internal\ (installed as

bin\_internal\). The executables load their runtime from

bin\_internal\; keep that folder next to the .exe files.

Option A2 — macOS disk image (easiest)

Apple Silicon only (M1 or newer); requires macOS 14 (Sonoma) or newer;

does not run on Intel Macs or on macOS 13 (Ventura).

  1. Download EasyMathLang-macOS-arm64.dmg from the latest stable release

on the GitHub Releases page

(or the nightly artifact under Actions -> "Build Installers").

  1. Open the .dmg and drag easy-math-editor.app to Applications

(a shortcut to Applications is included in the image for this).

The disk image contains:

   easy-math-editor.app   (helpers live inside the bundle:
                           Contents/MacOS/easy-math-lang, …)
   README.txt
  1. Run the app from Applications.

The app is ad-hoc signed, not notarized, so Gatekeeper will block

a plain double-click on first launch. Either:

  • right-click easy-math-editor.app → Open, then Open again

in the dialog; or

  • remove the quarantine flag yourself:

xattr -dr com.apple.quarantine /Applications/easy-math-editor.app

After the first launch it opens normally.

  1. Optional terminal use — the helpers live inside the app bundle:
   BIN="/Applications/easy-math-editor.app/Contents/MacOS"
   "$BIN/easy-math-lang" doc.ezmath

or add it to PATH (export PATH="$BIN:$PATH"), then

easy-math-lang doc.ezmath (PDF) or

easy-math-lang doc.ezmath out.png --format png (image).

See Export.

No further setup is needed: the editor finds the bundled helpers

automatically, even when nothing was added to PATH.

Option A3 — Linux packages (easiest)

x86_64 only. glibc 2.39 or newer is required (the packages are

built on Ubuntu 24.04); Ubuntu ≤ 22.04, Debian ≤ 11 or RHEL 8 will

not run them.

  1. Download EasyMathLang-Debian-amd64.deb (Debian, Ubuntu, Mint and

derivatives) or EasyMathLang-Fedora-amd64.rpm (Fedora, RHEL,

openSUSE and derivatives) from the latest

stable release on the

GitHub Releases page

(or the nightly artifact under Actions -> "Build Installers").

  1. Install it:
   sudo dpkg -i EasyMathLang-Debian-amd64.deb       # Debian/Ubuntu/Mint
   sudo rpm -i EasyMathLang-Fedora-amd64.rpm        # Fedora/RHEL/openSUSE

(On Debian/Ubuntu, if dpkg complains about missing dependencies,

run sudo apt-get install -f afterwards.)

  1. Launch Easy Math Editor from your applications menu, or run

easy-math-lang doc.ezmath in a terminal.

No further setup is needed: the programs install to the standard

locations (/usr/bin, /usr/lib/easy-math-lang), so the editor

finds its helper programs automatically.

Option A4 — Arch package

x86_64 only, glibc 2.39 or newer (Arch is a rolling release and

satisfies this by default).

  1. Download easy-math-lang-git-<version>-<rel>-x86_64.pkg.tar.zst from

the latest stable release on the

GitHub Releases page

(or the nightly artifact under Actions -> "Build Installers").

  1. Install it:
   sudo pacman -U easy-math-lang-git-<version>-<rel>-x86_64.pkg.tar.zst
  1. Launch Easy Math Editor from your applications menu, or run

easy-math-lang doc.ezmath in a terminal.

The package installs the same layout as the Debian/Fedora packages

(/usr/bin, /usr/lib/easy-math-lang), so the editor finds its helper

programs automatically. See Packaging and releases for

how it is built.

Option B — Run from source (all platforms)

What you need to install

Two things are required:

WhatWhy you need it
PythonThe language the compiler is written in
uvA tool that manages Python packages (think of it like an app store for Python)

Typst (the tool that turns your math text into a beautiful PDF) is now

installed automatically as a Python package (typst from PyPI) when you

run uv sync below — you do not need to install it separately.

Step 1 — Install Python

You need Python 3.12 or newer (see requires-python in pyproject.toml).

Windows

  1. Go to python.org/downloads
  2. Click the big yellow Download Python button
  3. Run the installer
  4. ⚠️ On the first screen, check "Add Python to PATH" before clicking Install

macOS

Requires macOS 14 (Sonoma) or newer (PySide6, the GUI toolkit, ships

no macOS 13 wheels since 6.12 — earlier releases work on macOS 13).

Open Terminal (press Cmd + Space, type "Terminal", press Enter) and run:

xcode-select --install

Then go to python.org/downloads and download the Mac installer.

Linux

Open a terminal and run:

sudo apt install python3 python3-pip

Step 2 — Install uv

> What is a terminal?

> A terminal (also called "command prompt" on Windows) is a window where you type

> commands instead of clicking buttons. Don't worry — you only need a few simple ones.

Windows — Open Command Prompt (press Win + R, type cmd, press Enter):

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

macOS / Linux — Open Terminal and run:

curl -LsSf https://astral.sh/uv/install.sh | sh

After it finishes, close the terminal and open a new one (this is needed for the change to take effect).

Check it worked by typing:

uv --version

You should see something like uv 0.x.x. If you do, it worked!

Step 3 — Download easy-math-lang

If you have Git installed:

git clone https://github.com/duo8097/easy-math-lang
cd easy-math-lang

Otherwise, go to the GitHub page, click the green Code button, then Download ZIP.

Unzip it, then open a terminal inside that folder.

> How to open a terminal in a folder:

> - Windows: Hold Shift and right-click the folder, then choose "Open PowerShell window here"

> - macOS: Right-click the folder in Finder, choose "New Terminal at Folder"

Step 4 — Install the project dependencies

Inside the project folder, run:

uv sync

This installs everything the project needs — including Typst (the PDF

engine, via the typst PyPI package). You only have to do this once.

You're ready!

To compile your first document, create a file called my-doc.ezmath inside the

project folder (any plain text editor works — even Notepad), write some content,

then run:

uv run easy-math-lang my-doc.ezmath

You will see your finished document appear:

  • my-doc.pdf — open this!

(The intermediate my-doc.typ is removed on success; pass

--save-build-artifacts to keep it for debugging.)

> Want to try immediately? The examples/ folder already contains finished

> documents. Run uv run easy-math-lang examples/example.ezmath and open

> examples/example.pdf.

> Want autocompletion and error checking in your editor? See the

> Language server guide.

Updating later

Once installed, you update with one command (or one click in the

editor):

  • easy-math-lang --update — checks GitHub Releases, shows what would

be installed (with release notes), asks Update now? [y/N], then

downloads, verifies SHA256SUMS.txt from the same release and hands

over to a small helper that installs it after the app exits. --yes

skips the prompt for scripts.

  • easy-math-lang --check-update — just reports whether a newer

release exists (always exits 0).

  • From source: git pull && uv sync (the tool never updates a source

checkout by itself).

Automatic update checks are on by default in the editor (about once a

day, silent on failure); see Updating and

Desktop editor.

Something went wrong?

ProblemSolution
uv: command not foundClose and reopen the terminal after installing uv
Python not foundRe-install Python and check "Add to PATH"
PDF looks emptyCheck your .ezmath file for typos
Editor installed from setup says LSP: DisconnectedKeep the installed folders together (bin\ and bin\_internal\ next to each other). Then use Build → Restart Language Server. If you moved the binaries, point EASYMATH_LSP_EXE / EASYMATH_COMPILER_EXE at the right files — see Desktop editor.
